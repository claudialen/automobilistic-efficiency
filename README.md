# Automobilistic Efficiency
In this repo you will find three different algorithms to solve an academic problem of automobilistic efficiency. 
The algorithms implemented are *exhaustive search*, *greedy algorithm*, and *metaheuristics*. 

The problem consists on optimizing the production line of an automobilistic factory that has different types of improvements and classes of cars. 
The goal is to make the process as efficient as possible, and minimize a certain penalty.
